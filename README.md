### 七、论文研究与课堂教学怎么衔接

正式教案首先必须是一节正常、顺畅的复习课，不能为了“采数据”搞得很怪。

课堂里只轻量嵌入研究观察：

- 学生初始预测 / 初始答案；
- 获得 pH 数字读数或实验现象之后是否提出新问题；
- 学生选什么证据；
- 如何解释；
- 是否修改原答案；
- 同伴 / 教师提示后发生了什么变化；
- 离堂条留一个“哪条证据让我确认 / 修改判断”的问题。

需要区分：

- **教学评价**：学生知识是否掌握、离子方程式是否写对；
- **研究观察**：学生如何提问、选证据、推理、修改观点。

不能把“答对了”直接编码成“探究动机高”。

原研究工具仍保留：

- 课前基线量表；
- IMI 情境量表；
- 疑问卡；
- 学习单；
- 课堂录像 / 重点小组录音；
- 刺激回忆访谈；
- 第二编码员复核约 20% 材料。

但 30 分钟课堂本体不要塞长问卷；问卷应放课前或课后。
