### 2. 研究定位

建议题目暂定为：

**《数字化实验中学生探究动机与证据推理的互动生成过程研究——以离子反应复习课为例》**

研究实施建议：

- 研究对象：一个高一班级。
- 课型：离子反应复习课。
- 教学时间：30分钟。
- 教学结构：基础实验层 + 进阶探究层。
- 研究方法：以课堂过程追踪和质性分析为主，量化资料为辅。
- 核心分析：学生的探究动机与证据推理如何在关键课堂事件中相互作用。
- 结论边界：分析单班课堂中的过程及典型个案，不据此推断普遍因果效应。

### 3. 研究问题

刘洋修改意见中明确提出的三个子问题：

1. 学生的探究动机如何被激活、维持？其结构类型有什么特征？
2. 探究动机的变化如何与证据选择、数据质量评价、化学解释、结论修正发生联系？
3. 哪些教师、同伴或任务条件支持或阻碍上述过程？

主问题建议采用既有草稿中的 A 版表述：

> 在数字化实验中，学生的探究动机与证据推理如何互动生成，数字化实验在其中起何种作用？

说明：仓库中的 0925 修改记录显示，主问题 A、B 当时尚待正式拍板。本方案采用 A 作为实施设计的工作表述，正式定稿前仍应与刘洋编定版核对。由于本次以单班过程追踪为主，不把数字化实验与传统实验的组间效果差异作为主要结论。

## 二、30分钟复习课：基础层与进阶层

本课采用不同难度的两个实验任务，围绕同一个核心知识组织：

**溶液中离子种类和数量的变化，以及离子反应的实质。**

两个层次面向全体学生依次开展，不固定划分所谓基础生、拔高生。这里的“分层”指任务难度与认知要求由浅入深，而不是给学生贴能力标签。

### 第一层：基础实验（0—6分钟）

**实验：盐酸与氢氧化钠的中和反应。**

**工具：便携式 pH 计。**

基本操作：

1. 测量稀盐酸的 pH。
2. 测量稀氢氧化钠溶液的 pH。
3. 将等浓度、等体积的两种溶液混合。
4. 测量混合液的 pH。
5. 学生写出离子反应方程式。

核心反应：

\[
\mathrm{H^+ + OH^- = H_2O}
\]

复习内容：

- 强酸、强碱的电离；
- 溶液酸碱性与离子的关系；
- 离子反应的实质；
- 离子方程式的书写。

这一层不追求复杂分析，主要让学生动手、观察、回忆已有知识，并熟悉基本测量操作。

**研究观察价值：**

- 学生是否能独立完成基本测量；
- 学生关注的是实验现象、测量工具还是化学原理；
- 学生是否主动提出问题；
- 操作熟练程度是否影响其后续参与。

### 第二层：进阶实验（6—30分钟）

**实验：向氢氧化钡溶液中逐滴加入稀硫酸，使用电导率传感器观察溶液导电能力变化。**

该实验沿用既有 lesson-plan-framework 中提出的离子反应实验，不是将研究载体更换为酸碱中和滴定。

总反应：

\[
\mathrm{Ba(OH)_2 + H_2SO_4 = BaSO_4\downarrow + 2H_2O}
\]

同时发生两种离子反应：

\[
\mathrm{Ba^{2+} + SO_4^{2-} = BaSO_4\downarrow}
\]

\[
\mathrm{H^+ + OH^- = H_2O}
\]

学生需要综合理解：

- 白色沉淀的形成；
- 溶液中离子组成的变化；
- 两个离子反应同时发生；
- 为什么导电能力会先下降、再回升；
- 实验曲线如何支持对离子变化的解释。

该实验的研究价值在于：数字化设备可以呈现连续变化的电导率曲线，曲线低谷及其前后变化可用于观察学生的预测、认知冲突、证据选择和解释修正。

**预期的探究链条：**

预测 → 观察真实曲线 → 产生疑问 → 选择数据 → 联系离子变化 → 解释现象 → 修正观点。

需要注意：曲线的具体形态和稳定性必须通过预实验确认，不能仅凭理论预期认定正式课堂一定出现理想 V 形曲线。

### 30分钟教学流程

| 时间 | 教学环节 | 学生活动 | 研究资料 |
|---|---|---|---|
| 0—2分钟 | 情境导入 | 明确复习任务 | 课堂录像 |
| 2—6分钟 | 基础实验：pH测量 | 动手测量、回忆离子反应 | pH记录、基础学习单 |
| 6—9分钟 | 进阶实验预测 | 独立预测电导率变化并说明理由 | 原始预测 |
| 9—14分钟 | 数字化实验 | 观察电导率实时变化及沉淀现象 | 曲线、录像、学生提问 |
| 14—17分钟 | 独立疑问记录 | 不讨论，各自记录问题 | 疑问卡 |
| 17—24分钟 | 小组解释 | 选择数据、解释离子变化、修正结论 | 小组推理单、录音 |
| 24—28分钟 | 全班交流 | 分享不同解释和证据 | 师生互动录像 |
| 28—30分钟 | 离堂条 | 写下最有力的证据及仍未解决的问题 | 个体学习成果 |

### 教师提问原则

保留原有教案框架中的开放式引导语：

> 大家观察到了什么？有什么想进一步探究的地方？

不要在学生自主观察之前直接提示：

- 为什么曲线先下降后上升？
- 为什么低谷出现在这里？
- 为什么离子减少了？

否则学生的疑问指向会受到教师提示，影响研究资料的真实性。

学生当场提问时，先请其记录，不立即回答或评价，统一留到解释环节处理。开放式引导语应尽量保持固定，避免不同小组受到不同程度的提示。

## 三、实证工具与数据采集

不重新发明测量工具，沿用原有草稿中的工具体系，主要调整施测时间和课堂使用方式。

| 工具 | 使用时间 | 研究用途 | 处理建议 |
|---|---|---|---|
| 课前基线量表 | 上课前一周 | 了解原有动机水平、辅助选择访谈对象 | 保留现有版本 |
| 学生学习单 | 课堂 | 记录预测、数据、解释和结论修正 | 必须 |
| 探究疑问卡 | 课堂 | 记录问题产生的时间与指向 | 必须 |
| pH测量记录 | 基础阶段 | 记录基础实验操作与结果 | 本次新增 |
| 电导率原始数据 | 进阶阶段 | 提供数字化证据 | 必须 |
| 课堂录像 | 全程 | 观察学生行为、教师支持和关键事件 | 必须 |
| 重点小组录音 | 进阶阶段 | 分析小组推理过程 | 强烈建议 |
| IMI情境量表36题 | 课后当天 | 测量课堂情境中的动机状态 | 保留 |
| 刺激回忆访谈 | 课后当天或次日 | 还原学生当时的想法和判断 | 保留 |
| 延迟IMI | 2—3周后 | 观察情境兴趣是否衰减 | 建议保留 |

### 量表使用注意

课前基线量表与课后 IMI 测量对象不同，不能直接相减。

课后当天与延迟后测应使用同一套 IMI 情境量表，才适合比较状态动机随时间的变化。

30分钟只限制课堂教学环节，不限制课前、课后的研究资料采集。

### 学习单建议结构

**第一部分：基础实验**

- 盐酸 pH：________
- 氢氧化钠溶液 pH：________
- 混合液 pH：________
- 离子方程式：________

**第二部分：进阶实验预测**

- 我认为电导率会怎样变化？
- 我的理由是什么？

**第三部分：实验后解释**

- 实际数据与预测有什么不同？
- 我选择了哪一段数据作为证据？
- 我如何解释溶液中离子的变化？
- 我是否修改了原来的观点？为什么？

**第四部分：剩余疑问**

- 我现在还有什么想弄明白的问题？

### 探究疑问卡

继续使用原有两栏结构：

| 现象或曲线出现之前 | 现象或曲线出现之后 |
|---|---|
| 基础实验后及进阶实验前产生的问题 | 看到数字化数据后产生的问题 |

每条疑问后保留：

> 我是看到了________才想问的。

这一设计是此前已经确认的研究工具要求，不应随意删掉。需在论文局限中说明：该提示格可能提醒学生将注意力放到观察对象上，从而影响提问。

## 四、编码与分析框架

严格沿用原有第三章、第四章框架，不另行增加新的理论体系。

### 1. 探究动机编码

重点观察学生的行为表现：

- 主动提问；
- 自发追问；
- 主动验证；
- 持续讨论；
- 困惑后继续尝试；
- 停滞、退缩或放弃。

同时区分动机来源：

- 认知冲突；
- 设备新奇。

兴趣性质：

- 触发性情境兴趣；
- 维持性情境兴趣；
- 萌发个人兴趣的迹象。

注意：单节课不能确证个人兴趣已经稳定形成。相关判断需要结合延迟测量、访谈及后续自主行为，只能谨慎讨论其萌发迹象。

### 2. 疑问指向编码

沿用原有分类：

| 类型 | 本次课的例子 |
|---|---|
| 宏观现象 | 为什么出现白色沉淀？ |
| 微粒作用 | Ba²⁺和SO₄²⁻去哪了？ |
| 符号系统 | 为什么离子方程式这样写？ |
| 曲线图像 | 为什么导电能力先下降再回升？ |
| 曲线外观 | 曲线为什么是这个形状？ |
| 设备操作 | 传感器怎么连接？ |
| 设备本身 | 这个探头如何测量导电能力？ |

原有边界继续保留：

- 设备操作类单独计数，不计入探究疑问；
- 曲线外观单独报告；
- 设备本身单独报告；
- 读图障碍单独记录，不混入疑问；
- 无法归类的内容如实保留，不强行归类。

### 3. 证据推理编码

沿用刘洋老师要求的四个环节：

| 环节 | 本课的观察对象 |
|---|---|
| 证据选择 | 学生选择曲线哪个位置、哪组数据作为依据 |
| 数据质量评价 | 是否相信读数，是否质疑仪器或操作 |
| 化学解释 | 能否解释两种离子反应及溶液中离子的变化 |
| 结论修正 | 是否改变原先的预测，为什么 |

另外保留原有 EBR 框架的五个成分：

- 前提；
- 主张；
- 规则；
- 证据；
- 数据。

以及 Chinn & Brewer 关于异常数据反应的既有编码思路。具体编码仍以仓库中 evidence-reasoning、question-coding 等既有文件为准。

### 4. 动机与推理的互动分析

以小组为单位建立课堂事件时间轴，观察动机和推理的先后变化。

典型事件链示例：

~~~mermaid
flowchart TD
 A["学生预测电导率上升"] --> B["获得真实曲线"]
 B --> C["产生疑问"]
 C --> D["引用曲线数据"]
 D --> E["同伴提出不同解释"]
 E --> F["联系离子变化"]
 F --> G["修改原有观点"]
 G --> H["产生新的探究问题"]
~~~

也可能出现另一种过程：

预测 → 看到曲线 → 怀疑仪器 → 不愿继续分析 → 教师提供支持 → 重新解释。

两种过程都应记录。研究不预设数字化实验一定产生积极作用。

### 5. 重点个案分析

建议选择3—4个重点小组，比较它们为什么产生不同的互动过程。

资料互证：

- 课堂录像：学生当时做了什么；
- 疑问卡：学生写下了什么；
- 学习单：学生如何预测、选择证据和修正解释；
- 电导率原始数据：当时实际出现了什么；
- 访谈：学生如何解释自己的行为和想法。

对不一致的材料也应保留，不能只选择支持预期结论的案例。

### 安全与实验实施

氢氧化钡具有腐蚀性，误食或接触可能造成严重伤害。进阶实验建议由教师操作，采用经学校批准的低浓度、小用量方案，做好个人防护和废液回收。未经实验室安全审批，不建议安排学生分组直接操作。

如果学校不允许使用氢氧化钡，应先重新评估可替代的离子反应实验，再调整实验方案；不能为了保留曲线而忽略实验安全和研究问题的一致性。

3. 第二编码员是否已经联系好。
4. pH计是否可用，电极校准和测量流程是否能在课堂时间内完成。
5. 30分钟课时是否得到授课教师和学校安排许可。

## 七、方案结论

本方案保留原论文的研究方向和既有研究工具，不改变刘洋老师提出的“探究动机与证据推理互动生成过程”这一核心。

课堂实施上采用两层递进：

- **基础层**：通过 pH 计完成简单、可动手的中和实验，复习离子反应核心概念和基础操作。
- **进阶层**：通过电导率数字化实验呈现更复杂的离子变化情境，观察学生如何从预测和现象走向证据、解释与结论修正。

研究重点不是比较谁的兴趣分数更高，而是追踪学生在真实课堂事件中如何产生问题、选择证据、评价数据、形成化学解释，以及这些推理活动如何与探究动机相互作用。
