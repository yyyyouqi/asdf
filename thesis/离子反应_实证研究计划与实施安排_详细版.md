# 《酸碱中和滴定》单班单课时实证研究计划与实施安排

——数字化实验中学生探究动机与证据推理互动生成过程研究

> 课例：苏教版《化学·选择性必修1·化学反应原理》专题3第二单元“溶液的酸碱性”中的“酸碱中和滴定”
>
> 核心数字化工具：pH传感器
>
> 研究限制：1个班、1课时正式教学；不设置对照班；不作长期动机因果推断。
>
> 已确认条件：课堂录像可实施；课后访谈可实施。
>
> 当前主要不确定项：pH传感器、滴定器材及试剂条件。

## 一、研究核心问题

研究重点从“数字化实验是否提高学生动机”调整为：

> 在酸碱中和滴定数字化实验过程中，学生的探究动机与证据推理如何在关键课堂事件中共同生成并发生变化？

可进一步拆为：

1. 学生在哪些数字化证据出现后产生提问、好奇、质疑或持续探究行为？
2. 学生如何使用 pH-V 曲线中的数据支持或修正自己的解释？
3. 探究动机的变化与证据使用、解释修正之间呈现怎样的时间序列关系？
4. 不同学生或小组在“突跃”这一关键事件后的反应有何差异？

## 二、研究边界

本研究不做：

- 实验班与对照班比较；
- 数字化与传统课堂因果效果比较；
- 一节课前后测推断稳定学习动机提升；
- 统计中介效应。

本研究重点做：

- 单班课堂过程追踪；
- 关键事件分析；
- 学生解释变化；
- 证据使用方式；
- 探究行为变化；
- 典型小组案例比较；
- 视频、学习单、数字化数据和访谈三角互证。

## 四、当前最先要确认的器材

由于录像和访谈已经没有问题，现在学校沟通重点只剩器材。

### A. 数字化设备

必须问：

1. 有没有 pH 传感器？
2. 几套？
3. 品牌型号？
4. 是否有配套数据采集器？
5. 是否能连接电脑实时绘图？
6. 是否能保存/导出 pH 数据？
7. 是否有标准缓冲液？
8. 是否能提前借用做预实验？

### B. 滴定设备

确认：

- 酸式滴定管；
- 碱式滴定管；
- 滴定管夹；
- 铁架台；
- 锥形瓶；
- 量筒；
- 烧杯；
- 胶头滴管；
- 是否有磁力搅拌器。

### C. 试剂

确认：

- HCl；
- NaOH；
- 可提供的浓度；
- 是否可以按教材浓度配制；
- 酚酞；
- 甲基橙/甲基红（如果课堂要比较指示剂）。

## 五、器材条件对应方案

### 方案A：有 pH 传感器，可实时采集

这是最优方案。

实施：

- pH传感器持续浸入待测溶液；
- 滴定过程中实时绘制 pH-V 曲线；
- 全班看投影；
- 学生做预测与解释。

### 方案B：有普通 pH 计，没有连续传感器

仍可实施，但数字化程度下降。

实施：

- 按教材体积节点测 pH；
- 接近终点时提高采样密度；
- 现场录入表格；
- 自动或手工绘制曲线。

### 方案C：完全没有 pH 测量设备

不建议直接沿用本方案正式实施。

应重新评估：

- 能否借设备；
- 是否换实验室；
- 是否换用学校已有数字传感器设计另一个课例。

## 六、预实验标准操作流程

### 1. 第一次：设备与曲线跑通

目标：确认“能不能做”。

操作：

1. 传感器校准；
2. 连接电脑；
3. 读取 HCl 初始 pH；
4. 设置数据采集；
5. 开始滴定；
6. 连续搅拌；
7. 保存完整曲线；
8. 导出数据。

记录：

- 初始 pH；
- 每个关键体积；
- 等量点附近 pH；
- 曲线是否有明显突跃；
- 传感器响应是否滞后；
- 总耗时。

### 2. 第二次：按正式课堂节奏模拟

目标：确认“45分钟内能不能教完”。

同时模拟：

- 教师提问；
- 学生预测时间；
- 实验时间；
- 数据分析时间；
- 小组讨论；
- 指示剂任务；
- 离堂条。

### 3. 预实验完成标准

必须满足：

- 曲线完整；
- 突跃清楚；
- 设备稳定；
- 数据可保存；
- 实验核心过程控制在10分钟左右；
- 课堂整体不超时；
- 教师清楚何时暂停、何时追问。

## 七、正式课堂的数据采集

### 1. 数据源

至少收集：

- pH传感器原始数据；
- 屏幕上的实时滴定曲线；
- 全班课堂录像；
- 重点小组讨论录音；
- 学生学习单；
- 离堂条；
- 课堂观察表；
- 课后访谈。

### 2. 重点小组

建议选择3—4组进行精细过程分析。

不必事先只选“成绩最好”的组。

更适合选择：

- 表达较活跃；
- 能产生讨论分歧；
- 便于录音；
- 学生构成有差异。

## 八、正式授课当天时间表

### T-30 min

- 打开电脑；
- 连接 pH 传感器；
- 打开软件；
- 检查投影；
- 完成校准；
- 检查录像和录音；
- 确认存储空间。

### T-20 min

- 安装滴定管；
- 准备 HCl、NaOH；
- 摆好锥形瓶；
- 安置探头；
- 放好废液容器；
- 把学习单按座位发好。

### T-10 min

- 测一次 HCl 初始 pH；
- 不保存为正式数据；
- 确认数值与预实验接近。

### T-5 min

- 清空软件旧数据；
- 打开正式采集文件；
- 开启屏幕录制；
- 检查录像机位。

### T0

正式开始上课。

## 九、课堂关键事件

本研究不要求整节课每句话都编码，而是先抓关键事件。

建议事件码：

| 编码 | 含义 | 示例 |
|---|---|---|
| P | Prediction 预测 | “我觉得pH应该一直均匀上升” |
| Q | Question 提问 | “为什么这里突然这么陡？” |
| E | Evidence 证据 | “19.95到20.05 mL变化特别大” |
| R | Reasoning 推理 | “因为这时剩余H⁺已经很少” |
| C | Conflict 冲突 | 同组学生给出不同解释 |
| M | Modification 修正 | 改画原预测曲线 |
| V | Verification 验证 | 要求看局部数据、重测 |
| W | Withdrawal 退缩 | “算了，等老师讲” |

## 十、重点分析的课堂片段

优先抓以下位置：

### 事件1：预测阶段

看学生是否：

- 主动提出理由；
- 机械画直线；
- 预测突跃；
- 对同伴预测产生冲突。

### 事件2：真实曲线开始偏离预测

看学生是否：

- 注意到差异；
- 提问；
- 修改；
- 无反应。

### 事件3：等量点附近突跃

这是最重要的关键事件。

观察：

- 谁首先发现；
- 谁提出问题；
- 谁调用具体数据；
- 谁进行微观解释；
- 谁修改观点。

### 事件4：指示剂选择

看学生是否能把新证据迁移到另一任务，而不是只记忆“酚酞可以”。

## 十一、学习单数据

学习单至少保留四类痕迹：

1. 原始曲线预测；
2. 真实实验数据记录；
3. 修改前后痕迹；
4. “我为什么修改”的文字说明。

不要让学生擦掉原答案。

最好明确要求：

> 修改时不要涂掉原答案，用另一种颜色补充。

这样后续才能看到认知变化。

## 十二、访谈样本选择

建议6—8人。

优先选择：

- 2名主动质疑并明显修正者；
- 2名讨论积极但解释摇摆者；
- 1—2名课堂沉默但学习单完整者；
- 1—2名出现退缩、困惑或没有修正者。

## 十三、刺激回忆访谈提纲

1. 实验前你原来觉得曲线会是什么样？
2. 你第一次觉得“和我想的不一样”是什么时候？
3. 哪一个数据最引起你的注意？
4. 看到突跃时你第一反应是什么？
5. 你当时是先相信自己的想法，还是相信曲线？
6. 你为什么最后改变/没有改变原来的解释？
7. 小组同学有没有影响你的判断？
8. 老师的哪一句追问对你有影响？
9. 如果没有实时曲线，只看酚酞颜色，你还会想到这些问题吗？
10. 如果再做一次，你最想验证什么？

避免诱导式问题，例如：

- “pH传感器是不是提高了你的兴趣？”
- “数字化实验是不是让你更喜欢化学？”

## 十四、编码框架

### 1. 探究动机

| 编码 | 含义 |
|---|---|
| MI | 好奇/兴趣 |
| MQ | 主动提问 |
| MP | 持续探究 |
| MV | 主动验证 |
| MW | 退缩/放弃 |

### 2. 证据推理

| 编码 | 含义 |
|---|---|
| ER-E | 识别证据 |
| ER-D | 引用具体数据 |
| ER-L | 建立证据与主张之间的理由 |
| ER-C | 比较多种证据 |
| ER-R | 根据证据修正解释 |
| ER-Q | 质疑证据质量 |

### 3. 互动关系

重点识别：

- 动机变化后出现更深入证据推理；
- 新证据冲突后产生提问；
- 同伴冲突引发重新验证；
- 推理成功后产生继续探究意愿；
- 数据复杂导致退缩。

使用“伴随出现”“随后出现”“呈现出互动关系”等表述，不直接写因果。

## 十六、分析步骤

1. 同步课堂视频、pH曲线和观察记录时间；
2. 建立整节课关键事件时间轴；
3. 先标出突跃出现时间；
4. 找到突跃前后学生反应；
5. 选择3—4个重点小组；
6. 精转写关键片段；
7. 编码动机行为；
8. 编码证据推理；
9. 标记观点修正；
10. 与学习单对应；
11. 用课后访谈补充学生当时的主观解释；
12. 比较不同小组事件链；
13. 寻找反例；
14. 形成2—4个典型案例。

典型事件链可以写成：

> P预测 → E数字证据 → Q质疑 → C同伴冲突 → R解释 → M修正

或：

> P预测 → E复杂数据 → W退缩 → 教师追问 → R重新解释

## 十七、可信度保障

为了避免研究结果只依赖研究者主观判断，至少做：

### 数据三角互证

同一结论尽量同时有：

- 视频；
- 学习单；
- 访谈；

支持。

### 保留反例

如果有学生：

- 对数字化曲线更困惑；
- 没有增加兴趣；
- 不愿继续分析；
- 直接等待答案；

这些也必须写。

### 明确研究限制

论文中说明：

- 单班；
- 单课时；
- 样本小；
- 过程研究；
- 不推断长期效果；
- 不宣称数字化实验必然提升动机。

## 十八、风险预案

| 风险 | 处理 |
|---|---|
| pH传感器坏 | 使用预实验真实曲线，并在研究记录中标注 |
| pH数据延迟 | 减慢滴加速度，等待读数稳定 |
| 曲线噪声 | 检查搅拌、探头、气泡、校准 |
| 课堂超时 | 压缩机械计算题，不压缩预测、讨论和修正 |
| 学生没人提问 | 不人为制造“精彩发言”，如实记录 |
| 曲线与预期略有差异 | 将差异作为数据质量讨论 |
| pH传感器不存在 | 改普通pH计离散采集，或重新选数字化方案 |

## 二十、开会汇报时的简短表述

> 我把课例重新核对到学校实际使用的苏教版选择性必修1教材后，决定把实证课例从泛化的“离子反应”收窄为专题3第二单元中的“酸碱中和滴定”。教材本身就安排了pH测量、滴定曲线和pH传感器，因此数字化实验与教材内容结合更自然。课堂准备以pH传感器实时采集滴定曲线为核心，让学生经历曲线预测、实时取证、发现突跃、解释、质疑和修正。研究仍然采用一个班一节课的过程研究，重点分析数字证据出现后学生探究动机和证据推理如何互动，不做对照班和因果效果比较。现在录像和访谈已经确定没有问题，剩下主要确认学校是否有pH传感器和滴定器材。
